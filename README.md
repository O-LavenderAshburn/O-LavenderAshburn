### Publications

**Empirical Sender-Side QUIC Parameter Tuning for
Low Earth Orbit Satellite Networks**
Oscar Ashburn, Alvin Valera, and Winston K.G. Seah
*IEEE PIMRC, 2026* · [IEEE Xplore](https://ieeexplore.ieee.org/abstract/document/11711861)

An empirical evaluation of the QUIC transport protocol under sender-side parameter tuning (buffering, flow control, congestion window limits, and acknowledgment timing) in an emulated LEO satellite testbed. The study measures the effect on download completion time and sender CPU utilization.

**Key findings:** The default `quic-go` parameters were largely sufficient, and aggressive tuning such as reduced packet limits and a shorter `MaxAckDelay` raised CPU overhead without improving download performance. One configuration did reduce completion time variance for moderate-size single-stream downloads on clear links, a lightweight optimization opportunity for LEO environments with limited congestion window packet caps.

**Keywords:** QUIC, Low Earth Orbit, satellite networks, flow control, network emulation
